# Ravi Prakash - Personal Portfolio

A modern, responsive personal portfolio website showcasing professional experience, skills, and contact information.

## 🌟 Features

- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with smooth animations and transitions
- **Accessibility**: WCAG compliant with keyboard navigation and screen reader support
- **Interactive Elements**: Typing animation, smooth scrolling, and scroll-triggered animations
- **Mobile Navigation**: Hamburger menu for mobile devices
- **SEO Optimized**: Proper meta tags and semantic HTML structure

## 🔧 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/codebyRPS/Personal-Portfolio.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Personal-Portfolio/docs
   ```

3. Open `index.html` in your browser or use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js (with npx)
   npx serve
   ```

4. Visit `http://localhost:8000` in your browser

## 📝 Sections

- **Home/Hero**: Introduction with animated typing effect
- **About**: Personal background and mission
- **Skills**: Technical expertise and capabilities
- **Experience**: Professional work history timeline
- **Contact**: Ways to connect

## 🎨 Customization

To customize this portfolio for your own use:

1. Update personal information in `docs/index.html`
2. Modify colors in `docs/styles.css` (look for the purple/magenta theme color `#a04da0`)
3. Replace images in the `docs/` folder
4. Update social links and contact information
